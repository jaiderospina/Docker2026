# GLPI Docker

## Tecnologías utilizadas

- Docker
- Docker Compose
- MariaDB
- GLPI

## Estructura

- Contenedor GLPI
- Contenedor MariaDB
- Persistencia mediante volúmenes
- Variables de entorno para seguridad

## Ejecución

docker compose up -d

## Acceso

http://localhost:8080

## Variables de entorno

Configurar el archivo .env basado en .env.example.
